# Frontend

The website patients see, built with React and TypeScript.

| Folder | What goes here |
|---|---|
| `public/` | Static files, such as images and icons |
| `src/pages/` | Full pages, such as login, dashboard and provider search |
| `src/components/` | Reusable pieces, such as charts, buttons and search results |
| `src/api/` | All calls to the backend, so they stay in one place |
| `src/types/` | TypeScript types for the data the API returns |

**Connects to:** the backend, through its URLs. Until an endpoint is ready, use fake data with the same shape, then switch to the real URL.
