# Analysis

Data exploration, method testing and any model training. This is where we show that our numbers can be trusted. The website doesn't run this code.

| Folder | What goes here |
|---|---|
| `notebooks/` | Jupyter notebooks for exploring data and comparing methods |
| `results/` | Final charts and tables to use in docs and the demo |

**Connects to:** the database for data, and the engine for the calculations being tested. Findings can shape which methods the website uses.
